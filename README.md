# Адаптивный одностраничник в качестве pet-проекта.

Проект представляет собой лендинг компании, оказывающей услуги по экспресс-доставке вакцин и биопрепаратов. Основной акцент сделан на чистой архитектуре проекта, семантической верстке, адаптивности и удобстве поддержки кода.

## 📋 Возможности проекта

* Адаптивный интерфейс для мобильных устройств, планшетов и десктопов(media queries).
* Семантическая верстка.
* Использование препроцессора **SCSS**.
* Именование классов по методологии **BEM**.
* Адаптивное мобильное меню (Hamburger Menu).
* Маска ввода номера телефона с помощью библиотеки **iMask**.
* Легкая масштабируемость и поддерживаемость проекта благодаря структуре проекта.

## 🎨 SCSS

В проекте используется модульная структура SCSS.

+ такие файлы как:
* `__variables.scss` — хранение переменных (цвета, размеры, отступы и др.);
* `__fonts.scss` — подключение и настройка шрифтов;
* `global.scss` — глобальные стили проекта;

## 🚀 Запуск проекта

1. Клонировать репозиторий:

```bash
git clone <repository-url>
```

2. Перейти в папку проекта:

```bash
cd project-name
```

3. Открыть файл `index.html` в браузере.

Или воспользоваться расширением **Live Server** в Visual Studio Code.
